# Originality Disclosure

## Project
Post Disaster Housing Finance

## Original Work Statement
This repository contains original StellarX Philippines hackathon work. The product concept, project-specific workflow, README, backend routes, frontend screens, and Soroban contract scaffold are customized for this submission.

## Allowed Reuse
The project intentionally uses allowed and encouraged building blocks:

- Stellar SDK and Freighter wallet APIs.
- Soroban Rust SDK and contract patterns.
- React, Vite, Express, Prisma, and SQLite open-source libraries.
- AI-assisted coding and debugging.
- OpenZeppelin Relayer: https://docs.openzeppelin.com/relayer

## Ecosystem Integration
OpenZeppelin Relayer is included as the declared integration path for this project.

The app includes an OpenZeppelin Relayer profile so disaster beneficiaries can be supported with gasless transaction submission when the relayer API key is configured.
